MachinaCAD 0.2.20 개발 버전
회로: 새 저항·전압원·커패시터·접지·배선에는 핀과 부품 데이터가 저장됩니다. 부품 이름과 값은 속성에서 변경할 수 있습니다. DC 계산 창의 '도면에서 넷리스트 생성'을 누른 뒤 계산하세요. 단순 배선 교차는 접속하지 않고 끝점·핀·T 접속이 닿으면 연결합니다. 커패시터는 DC에서 개방으로 처리합니다. 기존 단순 기호는 자동 인식하지 않습니다. 복사한 부품의 이름이 중복되면 수정해야 합니다.
MCAD는 회로 정보를 보존하지만 DXF는 그림만 내보내며 회로 핀·값·연결의 의미는 보존하지 않습니다. 기호 내부 분해 시 해당 부품 정보가 사라집니다. AC·과도해석·비선형 부품·ERC·DRC·풋프린트·Gerber 등 제조 파일은 아직 미지원입니다. PCB 도구는 외곽·패턴·패드 기호 수준입니다.
건축 도구는 벽·문·창의 2D 기호 수준입니다. 연결형 벽·자동 개구부·실·면적 관리 등은 아직 미지원입니다.
각도 치수·블록 내용 편집·전체 다중행 문자 기본 서식 및 기존 해치·선종류·색상·선가중치 지원을 유지합니다. 공유 정의 일괄 편집, 혼합 문자 서식, 완전한 치수 스타일·DXF 속성 보존 등은 미완성입니다.
새 .mcad 파일은 이전 버전에서 열리지 않습니다. 실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다.
