MachinaCAD 0.1.8 — 초기 웹 프로토타입

압축을 풀고 index.html을 브라우저로 엽니다. 자동 저장하지 않으므로 .mcad로 자주 저장하세요. 파일 이름 .mcad는 이 프로그램이 사용하는 JSON 기반 도면 형식입니다.

정밀 입력: 도구를 선택하고 첫 점을 클릭한 후 마우스로 방향을 지정하고 숫자를 입력한 뒤 Enter를 누릅니다. 선·연속선·이동·복사 등은 길이 또는 길이<각도(도)를 입력합니다. 예: 100 또는 100<30. 원은 반지름, 타원·사각형과 PCB 보드 외곽은 가로,세로(예: 100,50)를 입력합니다. 음의 각도는 100<-30처럼 입력합니다. 값은 하단에 나타납니다. Shift는 직교 제한을 임시 전환하며 F8은 직교 모드를 계속 켜거나 끕니다. 기본 단위는 mm입니다.

자석: F3 또는 화면 하단 자석 버튼으로 켜거나 끕니다. 기존 선의 끝점과 중간점, 사각형의 꼭짓점, 원의 중심과 사분점, 호의 끝점과 중심, 선 사이 교차점에 가까이 가면 표시와 이름이 나타납니다. 클릭하면 해당 좌표에 정확히 맞춥니다. 직교 또는 숫자 입력으로 방향·크기를 제한하면 그 제약과 충돌하는 스냅은 적용되지 않을 수 있습니다. 자석은 좌표를 맞추며, 이후 한 도형을 이동했을 때 다른 도형이 자동으로 따라 움직이는 구속 기능은 아닙니다.

건축 도구는 벽(두께 입력), 문, 창문을 2D 도형으로 만듭니다. 문이 벽을 자동으로 잘라내거나 건축 객체의 물량을 계산하지는 않습니다. 배선, 저항, 커패시터, 전압원, 접지와 PCB 외곽·패턴·패드 기호도 2D 도형으로 배치합니다. 도형은 묶인 스마트 부품이 아닙니다.

DC 계산: 회로 제도의 DC 계산을 열고 넷리스트를 수동으로 입력합니다. 예: V1 in 0 5, R1 in out 1k, R2 out 0 1k (각각 한 줄). 저항 R, 직류 전압원 V, 직류 전류원 I, 접지 0만 지원합니다. 노드 전압과 전압원 전류를 구하며 도면과 자동 연결되지 않고 넷리스트는 .mcad에 저장되지 않습니다. AC/과도 해석, 다이오드 및 트랜지스터는 지원하지 않습니다.

PCB 도구는 도면 초안용입니다. 실제 구리 폭, 전기 연결 검사, 풋프린트, 부품 목록, Gerber 및 드릴 파일은 지원하지 않습니다. 제조용 PCB 데이터로 사용할 수 없습니다.

ASCII DXF 선·원·호·타원·제어점 기반 평면 스플라인·단순 한 줄 문자·2D 폴리라인과 주요 단위를 지원합니다. 레이어 이름, 보이기·잠금 상태도 보존합니다. 선색, 선종류 등 표현할 수 없는 속성과 미지원 객체는 가져오기 전에 경고합니다. 해치·치수 객체·3D 등은 지원하지 않습니다. 일부 2D 블록 참조는 분해 경고 후 가져오며, 비균일·반전 축척이나 외부 참조 등은 지원하지 않습니다. 치수는 DXF에서 선과 문자로 분해되므로 치수 객체로 편집할 수 없습니다. PDF는 인쇄 창에서 저장하며 정확한 축척 출력을 지원하지 않습니다. 실무 도면은 별도 검증 후 사용하세요.

MachinaCAD 자체 소스와 새 스플라인·폴리라인 코드는 MIT 라이선스입니다. LICENSE를 확인하세요.

기능 키: F1 도움말, F2 간단한 작업 기록, F3 자석, F4 3D 객체 스냅(미지원), F5 2D 등각 방향 선택, F6 동적 3D 좌표계(미지원), F7 격자 표시, F8 직교, F9 격자 스냅, F10 45도 단위 극좌표 추적, F11 객체 스냅점의 수평·수직 추적, F12 동적 입력 켜기/끄기. F5 등각 방향은 F8 직교 또는 Shift 직교를 사용할 때 2D 각도 제약으로 적용됩니다. F8과 F10은 동시에 켜지지 않습니다. F12를 끄면 숫자 입력도 비활성화됩니다. Mac에서 F키가 미디어 키로 설정되어 있으면 Fn을 함께 눌러야 할 수 있습니다.

공통 제도: A는 세 점으로 호, X는 한 줄 문자를 그립니다. Shift+클릭으로 여러 객체를 선택해 함께 드래그·복제·삭제할 수 있습니다. 빈 공간에서 드래그하여 영역을 선택하고, 선택한 객체들을 함께 이동·복사·회전·축척·반전할 수 있습니다. 단, 문자가 포함된 선택의 반전은 지원하지 않습니다. 곡선의 교차 영역 선택은 선분 근사로 처리합니다. 레이어를 추가하고 선택·숨김·잠금·이름 변경할 수 있으며, 선택한 객체의 속성에서 레이어를 바꿀 수 있습니다. 원·호를 교차점까지 자르고 간격띄우기 할 수 있습니다. 실행 취소는 레이어 상태도 복원합니다.

0.1.7: Q 도구는 대각선 두 점 또는 가로,세로 수치로 타원을 그립니다. 타원의 2D DXF ELLIPSE 입출력과 SVG 출력이 가능합니다. 레이어 색상과 선종류, 블록의 그룹 구조, 해치, 다중 행 문자, 편집 가능한 치수 객체와 전체 DXF 호환은 아직 지원하지 않습니다.

0.1.8: P 연속선은 여러 정점을 가진 폴리라인 한 객체입니다. 점을 순서대로 누르고 Enter로 끝내거나 C로 닫습니다. DXF LWPOLYLINE의 열린/닫힌 상태와 곡선 bulge를 보존합니다. S는 제어점 기반 스플라인이며 점을 순서대로 누르고 Enter로 끝냅니다. DXF SPLINE의 차수, 노트, 제어점과 양수 가중치를 보존합니다. 스플라인 제어점의 개별 편집은 미지원이며 SVG/PDF 출력 시 곡선은 근사됩니다. 피팅점만 있는 스플라인, 불연속 내부 노트, 3D 곡선 등은 지원하지 않으며 경고합니다. 블록은 양의 균일 축척·회전·배열에 한해 개별 객체로 변환하므로 블록 구조나 속성이 보존되지 않습니다. 읽기 경고를 확인하세요.
