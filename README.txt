MachinaCAD 0.1.2 — 초기 웹 프로토타입

압축을 푼 다음 index.html을 브라우저에서 엽니다. 시작 화면에서 새 도면 또는 도면 열기를 선택하세요. 자동 저장되지 않으므로 .mcad 파일로 자주 저장하세요.

L 선, P 연속선, R 사각형, C 원, D 치수, V 선택, M 이동, T 자르기, E 연장, O 간격띄우기. F8 직교 모드 전환. Ctrl/Cmd+D 복제, Delete 삭제, Ctrl/Cmd+Z 실행 취소, Ctrl/Cmd+Shift+Z 다시 실행, Ctrl/Cmd+S 저장, Esc 취소, Space+드래그 화면 이동. 연속선은 Enter로 마칩니다. 버튼으로 기준점 복사, 거리 측정, 배열, 축척, 회전, 반전도 사용할 수 있습니다.

기본은 자유 각도입니다. Shift를 누르는 동안 선·치수·측정·이동과 복사 방향이 수평/수직으로 고정됩니다. F8 직교 모드가 켜져 있으면 Shift를 누르는 동안 임시로 자유 각도로 전환됩니다. 사각형은 Shift로 정사각형을 그립니다. 그리는 동안 하단에 선 길이가 나타납니다. 선택한 선은 속성에서 길이와 각도를 변경할 수 있습니다.

ASCII DXF의 LINE, CIRCLE, ARC, LWPOLYLINE, 2D POLYLINE을 가져오고 선·원·호로 내보냅니다. 불러올 때 지원하지 않는 객체는 경고합니다. 일부 단위가 지원되며, 단위 없는 파일은 mm로 해석합니다. 외부 참조, 블록, 텍스트, 치수 객체, 3D, 해치 등의 완전한 DXF 호환은 아직 지원하지 않습니다. DXF의 폴리라인은 편집 가능한 선·호로 분해됩니다. DXF로 치수를 내보내면 숫자가 빠집니다. PDF는 내보내기 메뉴의 인쇄 창에서 PDF 저장을 선택합니다. PDF는 용지에 맞춰 출력되며 정확한 축척 출력은 아직 지원하지 않습니다.

자르기와 연장은 선 객체에 한정되며 경계로 선·사각형·원을 사용할 수 있습니다. 실제 레이어 편집과 다중 선택은 지원하지 않습니다. 실무 도면에는 별도 검증 후 사용하세요.
