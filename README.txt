MachinaCAD 0.2.10 개발 버전
선형 치수: 정렬·수평·수직·각도 지정 치수의 기준점, 치수선 간격과 방향을 편집하고 지원되는 DXF DIMENSION 객체로 가져오고 내보냅니다. 치수 스타일, 사용자 문자, 연관 관계, 각도·반지름 등 다른 치수 유형과 비균일 축척된 일부 치수는 지원하지 않습니다.
DXF 레이어와 일부 객체의 색상, 트루컬러, 선가중치 및 단순 파선 선종류를 화면과 SVG·PDF에 표시하고 DXF 왕복 시 보존합니다. 블록별 상속, 복합 선종류, 전역 선종류 축척은 제한되며 폴리라인의 파선 위상은 구간마다 다시 시작할 수 있습니다. 가져오기 경고를 확인하세요.
외부 DXF 참조는 시작 화면의 '참조 DXF 선택'에서 파일을 선택한 다음 주 도면을 여세요. 참조는 독립 블록 사본이며 자동 갱신되지 않습니다. DWG 참조, 오버레이, 순환 참조는 지원하지 않습니다.
이중 패턴, 그라데이션, 지나치게 촘촘한 패턴, 타원·스플라인 해치 경계와 비균일 축척된 원호 경계는 지원하지 않습니다. 공유 블록 정의 일괄 편집, 다중행 문자 서식, 모든 DXF 속성 보존은 미지원입니다. 유리·고차 스플라인 SVG/PDF 출력에도 제한이 있습니다.
새 .mcad 파일은 이전 버전에서 열리지 않으므로 중요한 도면은 원본을 백업하세요. 실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다.
