MachinaCAD 0.2.15 개발 버전
이중 해치: 닫힌 경계를 선택하고 이중 해치 버튼으로 교차 패턴을 만들 수 있습니다. DXF 사용자 정의 실선 패턴의 이중 플래그를 지원하며 미리 정의된 패턴의 이중 플래그는 표시에서 무시합니다. 비균일 축척은 두 독립 선 패턴으로 정규화하므로 원본 이중 플래그 자체는 유지하지 않습니다.
타원·제어점 기반 스플라인 해치 경계를 DXF에서 보존하고, 전체 타원·닫힌 스플라인에서 해치를 만들 수 있습니다. 피팅점만 있는 스플라인 경계는 미지원이며 유리·고차 스플라인 표시는 근사됩니다.
기존 선종류·선형 치수·색상·선가중치 지원을 유지합니다. 공유 블록 정의 편집, 나머지 치수 유형과 스타일, 다중행 문자 서식, 그라데이션, 모든 DXF 속성 보존은 아직 미완성입니다.
외부 참조는 독립 DXF 사본이며 원본 연결·자동 갱신은 유지하지 않습니다.
새 .mcad 파일은 이전 버전에서 열리지 않습니다. 실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다.
