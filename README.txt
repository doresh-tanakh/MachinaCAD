MachinaCAD 0.2.0 개발 버전
다중행 문자의 입력 폭에 맞춘 자동 줄바꿈을 지원합니다. 글꼴 차이로 다른 CAD와 줄바꿈이 다를 수 있으며 문자별 서식은 지원하지 않습니다.
지원 객체의 DXF 색상 인덱스, 트루컬러, 선가중치는 내보내기까지 보존되지만 화면에는 표시되지 않습니다. 레이어 색상과 선종류 등은 보존하지 않습니다. 가져오기 경고를 확인하세요.
외부 참조, 블록 공유 정의 일괄 편집, 패턴 해치, 완전한 치수 객체 및 모든 DXF 속성은 아직 지원하지 않습니다. 비균일 축척의 일부 객체와 스플라인 SVG/PDF 출력도 제한됩니다.
브라우저 화면 및 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다. 새 .mcad 파일은 이전 버전과 호환되지 않을 수 있으므로 중요한 도면은 원본을 백업하세요.
