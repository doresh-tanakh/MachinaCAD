MachinaCAD 0.2.24 — 개발 버전 (MIT)

실행
웹: ZIP을 풀고 index.html을 엽니다. 전용 .mcad 파일은 불러오기에서 선택합니다.
데스크톱: 운영체제와 CPU에 맞는 개발용 설치 파일을 사용합니다. 인증서가 없는 미서명 빌드입니다.
실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다.

건축
새 벽은 두께와 중심선, 문·창 개구부를 보존하는 객체입니다. 벽을 선택한 뒤 속성에서 두께를 편집하거나 개구부 종류·시작점으로부터 거리·폭·문 열림 방향을 입력하고 추가합니다. 목록에서 개구부를 삭제할 수 있습니다. 기존 독립 문·창 도구는 기호만 그립니다. 새 벽의 문·창은 벽을 이동·90도 회전·반전·균일 축척할 때 함께 변환됩니다. 개구부는 서로 겹칠 수 없고 벽 길이 안에 있어야 합니다. 벽끼리 자동 접합하거나 방을 자동 인식하지 않습니다. 벽 길이 변경과 복잡한 곡선벽, 층·높이·구조 해석, BIM/IFC는 미지원입니다.
닫힌 직선 폴리라인 또는 사각형을 선택해 실 영역으로 지정하면 면적·둘레를 계산합니다. 홀·곡선이 있는 실 경계는 미지원입니다.

회로
저항·커패시터·인덕터·전압원·접지·배선에는 회로 정보가 저장됩니다. 부품 속성에서 이름과 값을 편집합니다. 부품 핀 또는 배선 끝점이 닿는 경우 연결되고, 끝점 없이 교차만 하는 배선은 연결되지 않습니다. DC 또는 AC 모드를 선택한 다음 도면에서 넷리스트 생성을 누릅니다.
DC는 선형 동작점 계산이며 C는 개방, L은 단락으로 처리합니다. 직접 입력하는 넷리스트는 R/C/L/V/I를 지원합니다.
AC는 단일 주파수의 선형 정현파 정상상태입니다. 주파수를 Hz로 입력합니다(예: 1k). 전원 구문은 V1 in 0 AC 1 또는 V1 in 0 AC 1 90 (위상은 도)입니다. DC 숫자만 있는 전원은 AC에서 0으로 처리됩니다. 도면의 전압원 값은 AC 넷리스트 생성 시 AC 크기로 사용됩니다. 결과는 같은 기준의 크기와 위상이며 RMS/피크 변환은 하지 않습니다. 과도해석, 반도체·비선형 모델, 디지털 회로, ERC, 전체 SPICE 호환은 미지원입니다.

PCB
새 보드·배선·패드는 네트·위/아래 동박층·폭·드릴 데이터를 저장합니다. 관통 패드만 양쪽 층을 연결합니다. 기본 검사에서 네트 사이 단락·간격, 배선 폭, 드릴 지름, 홀 주변 동박, 보드 경계와 끊긴 네트를 검사합니다. 규칙 수치는 제조사에 맞춰 지정해야 하며 전체 DRC를 의미하지 않습니다. 사각형 보드 외곽 하나·직선 배선·원형 패드에 한정됩니다. 예전 단순 기호는 자동으로 설계 객체가 되지 않습니다.
내보내기 → PCB Gerber·드릴 ZIP 또는 PCB 기본 검사 창에서 출력합니다. 기본 검사의 모든 항목을 해결해야 출력됩니다. 앞·뒤 동박, 패드의 솔더마스크 개구부, 사각 외곽, 관통 홀 드릴, 설명서를 묶습니다. 외곽 좌하단을 공통 원점으로 사용하며 바닥층을 반전하지 않습니다. 모든 드릴은 도금 관통 홀로 의도됩니다. 마스크 확장은 패드 반지름에 더하며 배선에는 개구부를 만들지 않습니다. 제조 전 독립 CAM 도구에서 모든 층·홀·원점과 적층/도금/완성 홀 크기를 검토해야 합니다. 기본 검사 통과와 파일 생성은 제조 승인을 의미하지 않습니다.
실제 부품별 풋프린트 라이브러리·자동 배선·구리면·써멀·임피던스·슬롯·비도금 홀·스텐실·실크스크린·완전한 DRC는 미지원입니다. 일반 CAD 선·문자와 회로 도면은 Gerber 출력에 포함하지 않습니다.

파일과 호환성
.mcad는 MachinaCAD 전용 확장명입니다. 이번 도면 버전은 24이며 이전 버전에서 열 수 없습니다. 원본은 보관하세요. DXF는 벽·실·회로·PCB의 설계 데이터를 보존하지 않고 도형·주석으로 출력합니다. 공유 블록 정의 편집, 혼합 문자 서식, 완전한 치수 스타일·DXF 속성 보존, 일부 곡선 출력 정확도 등의 제한도 남아 있습니다.

시험 예제
examples/architecture.mcad: 벽 네 개, 부착 문·창, 실 영역.
examples/circuit-rc.mcad: 전압원·1k 저항·1u 커패시터. AC 모드에서 도면 넷리스트를 생성하고 약 159.154943 Hz에서 계산하면 출력은 약 0.707107 V, -45°입니다. DC에서 출력은 약 1 V입니다.
examples/pcb-two-pad.mcad: 같은 네트의 관통 패드 두 개와 위쪽 배선. 기본 검사 및 ZIP 출력 시험용.

검증
Node 회귀 검사: DC/AC 해석식 비교, 도면 연결, 벽 개구부·변환·실행 취소, PCB 기본 규칙 및 출력 좌표, 기존 2D/DXF 검사.
독립 Gerbonara 파서: 표본 Gerber의 층·좌표·배선 폭·패드 크기·마스크 극성·닫힌 외곽 및 Excellon 홀 좌표·지름·도금 지정, ZIP CRC 확인.
자동화 검사는 브라우저 화면이나 설치 후 실행 검사를 대신하지 않습니다.

0.2.24 회로·PCB 연결
같은 문서의 회로 부품을 선택하고 “선택 부품 → 두 핀 패드”를 누르면 지정한 좌표·간격에 두 관통 패드를 묶어 배치합니다. 부품별 검증된 풋프린트가 아니므로 데이터시트와 실제 핀 배치를 확인하세요. 패드는 부품 이름과 핀 1/2를 보존합니다. 회로 기호의 첫 단자가 핀 1, 두 번째가 핀 2입니다.
독립 패드도 속성에서 부품·핀 번호를 지정하거나 해제할 수 있습니다. PCB 검사 창의 핀 매핑 검사는 누락·중복·없는 핀과 회로도 네트 불일치를 보고합니다. “회로 네트 → 패드 적용”은 연결된 패드의 네트를 현재 도면으로 갱신하며 배선 네트는 자동 변경하지 않습니다. 회로·연결을 바꾸면 다시 적용하고 PCB 기하 검사를 수행하세요. 회로도와 연결한 패드는 같은 문서에 원본 회로가 있어야 하며 핀 매핑 검사를 통과해야 Gerber로 내보낼 수 있습니다.
회로 연결 검사는 접지·중복 부품·같은 노드 핀 오류와 단독 핀 네트 등을 확인합니다. 전기적 핀 유형·구동 충돌·부품 정격을 다루는 전체 ERC는 아닙니다. 현재 도면 연결은 두 단자 R/V/C/L 부품에 한정되며 다핀 IC·라이브러리·별도 회로도 파일 연결·자동 에어와이어는 미지원입니다.
examples/circuit-pcb-linked.mcad에는 회로 부품 세 개와 핀을 지정한 패드 여섯 개가 있습니다. 미배선 예제로 기본 PCB 검사에서 끊긴 네트를 보고하는 것이 정상이며, 배선을 완료하기 전에는 제조 출력할 수 없습니다.

개발·재현
소스 묶음 또는 GitHub 저장소 루트에서 npm ci 후 npm start로 Electron 개발 실행을 시작합니다. Node 회귀 검사는 tests/README.md를 참고하세요. macOS 설치 파일은 해당 플랫폼에서 npm run build:mac:arm64 또는 npm run build:mac:x64, Windows x64는 npm run build:win으로 빌드합니다. 개발용 무서명 macOS 빌드는 CSC_IDENTITY_AUTO_DISCOVERY=false를 지정합니다. 정식 서명·공증에는 별도 인증서와 계정이 필요합니다.
