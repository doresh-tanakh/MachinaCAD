MachinaCAD 0.2.21 개발 버전
건축: 사각형 또는 직선 폐합 폴리라인 하나를 선택하고 '실 영역'을 누르면 실 이름, 면적(m²), 둘레(m)를 관리할 수 있습니다. 형상이 변하면 주석이 다시 계산됩니다. 교차·겹침 경계, 곡선 경계와 구멍이 있는 실은 미지원입니다. 벽·문·창은 기존 2D 기호이며 연결형 벽·자동 개구부 등은 아직 없습니다.
회로: 새 부품·배선의 핀과 값을 저장하고 DC 계산 창에서 '도면에서 넷리스트 생성' 후 계산할 수 있습니다. 단순 배선 교차는 접속하지 않으며 끝점·핀·T 접속을 연결합니다. 저항·전압원·접지를 지원하고 커패시터는 DC에서 개방으로 처리합니다. 기존 단순 기호는 자동 인식하지 않으며 복사한 부품의 이름 중복은 수정해야 합니다.
AC·과도해석·비선형 부품·ERC·DRC·풋프린트·Gerber 등은 미지원입니다. PCB 도구는 외곽·패턴·패드 기호 수준입니다.
MCAD는 실·회로 데이터를 보존하지만 DXF는 주석과 그림만 내보내며 설계 의미와 연결을 보존하지 않습니다.
기존 치수·블록 내용 편집·기본 문자 서식·해치 지원을 유지합니다. 공유 블록 정의 일괄 편집, 혼합 문자 서식, 완전한 치수 스타일·DXF 속성 보존 등은 미완성입니다.
새 .mcad 파일은 이전 버전에서 열리지 않습니다. 실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다.
