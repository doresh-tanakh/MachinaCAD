MachinaCAD 0.1.4 — 초기 웹 프로토타입

압축을 풀고 index.html을 브라우저로 엽니다. 자동 저장하지 않으므로 .mcad로 자주 저장하세요. 파일 이름 .mcad는 이 프로그램이 사용하는 JSON 기반 도면 형식입니다.

정밀 입력: 도구를 선택하고 첫 점을 클릭한 후 마우스로 방향을 지정하고 숫자를 입력한 뒤 Enter를 누릅니다. 선·연속선·이동·복사 등은 길이 또는 길이<각도(도)를 입력합니다. 예: 100 또는 100<30. 원은 반지름, 사각형과 PCB 보드 외곽은 가로,세로(예: 100,50)를 입력합니다. 음의 각도는 100<-30처럼 입력합니다. 값은 하단에 나타납니다. Shift는 직교 제한을 임시 전환하며 F8은 직교 모드를 계속 켜거나 끕니다. 기본 단위는 mm입니다.

자석: F3 또는 화면 하단 자석 버튼으로 켜거나 끕니다. 기존 선의 끝점과 중간점, 사각형의 꼭짓점, 원의 중심과 사분점, 호의 끝점과 중심, 선 사이 교차점에 가까이 가면 표시와 이름이 나타납니다. 클릭하면 해당 좌표에 정확히 맞춥니다. 직교 또는 숫자 입력으로 방향·크기를 제한하면 그 제약과 충돌하는 스냅은 적용되지 않을 수 있습니다. 자석은 좌표를 맞추며, 이후 한 도형을 이동했을 때 다른 도형이 자동으로 따라 움직이는 구속 기능은 아닙니다.

건축 도구는 벽(두께 입력), 문, 창문을 2D 도형으로 만듭니다. 문이 벽을 자동으로 잘라내거나 건축 객체의 물량을 계산하지는 않습니다. 배선, 저항, 커패시터, 전압원, 접지와 PCB 외곽·패턴·패드 기호도 2D 도형으로 배치합니다. 도형은 묶인 스마트 부품이 아닙니다.

DC 계산: 회로 제도의 DC 계산을 열고 넷리스트를 수동으로 입력합니다. 예: V1 in 0 5, R1 in out 1k, R2 out 0 1k (각각 한 줄). 저항 R, 직류 전압원 V, 직류 전류원 I, 접지 0만 지원합니다. 노드 전압과 전압원 전류를 구하며 도면과 자동 연결되지 않고 넷리스트는 .mcad에 저장되지 않습니다. AC/과도 해석, 다이오드 및 트랜지스터는 지원하지 않습니다.

PCB 도구는 도면 초안용입니다. 실제 구리 폭, 전기 연결 검사, 풋프린트, 부품 목록, Gerber 및 드릴 파일은 지원하지 않습니다. 제조용 PCB 데이터로 사용할 수 없습니다.

ASCII DXF 선·원·호·2D 폴리라인과 일부 단위를 지원하며 다른 객체는 경고합니다. 블록·문자·치수 객체·3D 등은 지원하지 않고 폴리라인을 선과 호로 분해합니다. DXF로 치수를 내보내면 숫자가 빠집니다. PDF는 인쇄 창에서 저장하며 정확한 축척 출력을 지원하지 않습니다. 실무 도면은 별도 검증 후 사용하세요.
