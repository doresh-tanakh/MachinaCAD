MachinaCAD 0.2.8 개발 버전
정렬 치수: 선택 후 속성의 '치수선 간격'을 변경할 수 있습니다. 지원되는 정렬 치수는 DXF DIMENSION 객체로 가져오고 내보냅니다. 치수 스타일, 사용자 문자, 연관 관계, 다른 치수 유형 및 비균일 축척된 일부 치수는 지원하지 않습니다.
DXF 레이어와 일부 객체의 색상, 트루컬러 및 선가중치를 화면과 SVG·PDF 출력에 반영하고 DXF 왕복 시 보존합니다. 블록별 색상 상속, 선종류와 다른 DXF 속성은 보존에 제한이 있습니다.
외부 DXF 참조: 시작 화면의 '참조 DXF 선택' 또는 편집 화면 상단의 '참조 DXF'에서 참조 DXF 파일을 선택한 다음 주 도면을 여세요. 참조는 독립 블록 사본으로 삽입되며 자동 갱신되지 않습니다. DWG 참조, 오버레이, 순환 참조는 지원하지 않습니다.
이중 패턴, 그라데이션, 지나치게 촘촘한 패턴, 타원·스플라인 해치 경계와 비균일 축척된 원호 경계는 지원하지 않습니다. 공유 블록 정의 일괄 편집, 다중행 문자 서식, 모든 DXF 속성 보존은 미지원입니다. 유리·고차 스플라인 SVG/PDF 출력에도 제한이 있습니다.
새 .mcad 파일은 이전 버전에서 열리지 않으므로 중요한 도면은 원본을 백업하세요. 실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다.
