MachinaCAD 0.2.22 개발 버전
PCB: 새 외곽·배선·패드에는 PCB 데이터가 저장됩니다. 속성에서 네트, 위/아래 동박층, 배선 폭과 드릴을 지정할 수 있습니다. 기본 검사에서 지정된 간격·최소 폭·드릴·홀 주변 동박·보드 경계와 같은 네트의 끊김을 검사합니다. 관통 패드만 두 동박층을 연결합니다. 검사 값은 제조사 규칙에 맞게 지정해야 하며 전체 DRC 또는 제조 승인을 의미하지 않습니다.
사각형 외곽 하나와 원형 패드·직선 배선만 지원합니다. 풋프린트, 회로도와 PCB의 자동 넷 연결, 솔더마스크·구리면·제조 출력은 아직 없습니다. 이전 단순 기호는 자동으로 PCB 객체가 되지 않습니다. DXF 출력은 그림 외곽만 보존하고 PCB 설계 데이터를 보존하지 않습니다.
기존 실 영역·면적·둘레, 도면 기반 DC 회로 계산, 2D 치수·블록 내부 편집·기본 문자 서식·해치 기능을 유지합니다. 건축 연결형 벽·자동 개구부, AC/과도 회로 해석, 공유 블록 정의·혼합 문자 서식·완전한 치수 스타일과 DXF 보존 등은 미완성입니다.
새 .mcad 파일은 이전 버전에서 열리지 않습니다. 실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다.
