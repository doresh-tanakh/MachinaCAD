MachinaCAD 0.2.18 개발 버전
블록 내부 편집: 블록을 선택하고 속성의 '블록 내용 편집'을 누릅니다. 내부 객체를 편집한 뒤 상단 적용 또는 취소로 돌아갑니다. 중첩 편집과 실행 취소를 지원하며 저장·열기·내보내기는 편집 완료 후 사용할 수 있습니다. 독립 블록 사본을 편집하는 기능이며 공유 정의의 모든 인스턴스에 자동 반영하는 기능은 아직 없습니다.
각도·선형·반지름·지름 치수와 기존 선종류·색상·선가중치 지원을 유지합니다. 이중 해치, 타원·제어점 스플라인 경계 및 비균일 축척 경계를 일부 지원합니다. 치수 스타일·연관 관계, 피팅점 전용 스플라인, 유리·고차 스플라인의 정확한 화면·SVG 표시는 제한됩니다.
공유 블록 정의 일괄 편집, 다중행 문자 서식, 그라데이션과 모든 DXF 속성 보존은 미완성입니다. 외부 참조는 독립 DXF 사본이며 원본 연결·자동 갱신은 유지하지 않습니다.
새 .mcad 파일은 이전 버전에서 열리지 않을 수 있습니다. 실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다.
