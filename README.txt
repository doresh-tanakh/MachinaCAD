MachinaCAD 0.2.16 개발 버전
원 하나를 선택하고 반지름 치수 또는 지름 치수 버튼을 눌러 독립 치수를 만들 수 있습니다. 지원되는 DXF 반지름·지름 치수의 측정 데이터와 객체 유형을 보존합니다. 원본 객체와 연관되지 않으며 스타일·지시선·사용자 문자 배치는 보존되지 않습니다. 비균일 축척된 원형 치수와 각도 치수는 아직 미지원입니다.
이중 해치와 타원·제어점 스플라인 경계 지원, 비균일 축척 경계의 기하 변환을 포함합니다. 피팅점 전용 스플라인은 미지원이며 유리·고차 스플라인 표시는 근사됩니다.
선종류·선형 치수·레이어 및 객체 색상·선가중치의 기존 지원을 유지합니다. 공유 블록 정의 편집, 다중행 문자 서식, 그라데이션과 모든 DXF 속성 보존은 미완성입니다.
외부 참조는 선택한 DXF를 독립 블록 사본으로 가져오며 원본 연결·자동 갱신은 유지하지 않습니다.
새 .mcad 파일은 이전 버전에서 열리지 않습니다. 실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다.
