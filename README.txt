외부 DXF 참조: 시작 화면의 '참조 DXF 선택' 또는 편집 화면 상단의 '참조 DXF'를 눌러 참조 DXF 파일을 모두 선택한 다음 주 도면을 여세요. 경로의 파일 이름을 대소문자 구분 없이 비교합니다. 이름이 같은 참조 파일은 구분할 수 없으며 한 번에 20개, 파일당 25MB까지 선택할 수 있습니다.
참조는 독립 블록 사본으로 삽입됩니다. 연결이나 자동 갱신은 유지되지 않고 레이어 설정은 주 도면을 따릅니다. DWG 참조, 오버레이, 순환 참조와 일부 미지원 객체는 가져오지 않으며 경고를 확인해야 합니다. 참조 파일을 바꾸려면 다시 선택하고 주 도면을 여세요.
DXF에서 선·파선·점 패턴 해치를 가져오고 내보냅니다. 이중 패턴, 그라데이션, 지나치게 촘촘한 패턴과 타원·스플라인 경계, 비균일 축척된 원호 경계는 지원하지 않습니다.
공유 블록 정의 일괄 편집, 완전한 치수, 다중행 문자 서식, 모든 DXF 속성 보존은 미지원입니다. 색상과 선가중치는 일부 객체에 보존되지만 화면에 반영되지 않습니다. 유리·고차 스플라인 SVG/PDF 출력에도 제한이 있습니다.
새 .mcad 파일은 이전 버전에서 열리지 않을 수 있으므로 중요한 도면은 원본을 백업하세요. 실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다.
