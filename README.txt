MachinaCAD — 초기 웹 프로토타입

index.html을 Chrome, Edge, Safari 등에서 열어 사용합니다.
도형 도구를 선택한 뒤 시작점과 끝점을 각각 클릭합니다.
선택 도구에서는 객체 선을 클릭하고 드래그하여 이동합니다.
격자 스냅을 끄면 자유롭게 위치를 지정할 수 있습니다.
저장 버튼은 .mcad 파일을 다운로드하며, 열기 버튼으로 다시 불러옵니다.

단축키: V 선택, L 선, R 사각형, C 원, D 치수, Delete 삭제,
Ctrl/Command+Z 실행 취소, Ctrl/Command+Shift+Z 다시 실행,
Ctrl/Command+S 저장, Esc 취소, Space+드래그 화면 이동, 휠 확대/축소.

이 버전은 초기 프로토타입입니다. DXF 내보내기는 선과 원을 사용하며 치수 텍스트는 포함하지 않습니다. DXF 불러오기, 호, 객체 스냅, 다중 선택, 실제 레이어 편집은 지원하지 않습니다. 작업은 자동 저장되지 않으므로 저장 버튼으로 보관하세요. macOS 및 Windows 설치형 앱은 아직 만들어지지 않았습니다.
