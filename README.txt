MachinaCAD 0.2.4 개발 버전
원을 포함한 닫힌 경계를 선택하고 단색 채우기 또는 ANSI31 선 패턴 해치를 만들 수 있습니다. 생성된 해치는 원래 경계와 연결되지 않습니다.
DXF의 선·파선·점 패턴 해치를 가져오고 내보냅니다. 직선 경계의 블록 내부 패턴은 회전·반전·비균일 축척도 처리합니다. 이중 패턴, 그라데이션, 지나치게 촘촘한 패턴과 타원·스플라인 경계는 지원하지 않습니다. 비균일 축척된 원호 경계도 지원하지 않습니다. 가져오기 경고를 확인하세요.
외부 참조, 공유 블록 정의 일괄 편집, 완전한 치수, 다중행 문자 서식, 모든 DXF 속성 보존은 미지원입니다. 색상과 선가중치는 일부 객체에 보존되지만 화면에 반영되지 않습니다.
유리·고차 스플라인 SVG/PDF 출력에도 제한이 있습니다. 새 .mcad 파일은 이전 버전에서 열리지 않으므로 중요한 도면은 원본을 백업하세요.
실제 브라우저 화면과 설치 후 실행은 검증하지 못했습니다. 설치 파일은 미서명 개발용입니다.
