MachinaCAD 0.1.1 — 초기 웹 프로토타입

압축을 푼 후 index.html을 브라우저에서 엽니다. 작업은 자동 저장되지 않으므로 저장 버튼을 사용하세요.

L 선, R 사각형, C 원, D 치수, M 거리 측정, V 선택, T 자르기, E 연장, O 간격띄우기.
F8 직교 켜기/끄기, Ctrl 또는 Cmd+D 복제, Delete 삭제, Ctrl 또는 Cmd+Z 실행 취소,
Ctrl 또는 Cmd+Shift+Z 다시 실행, Ctrl 또는 Cmd+S 저장, Esc 취소, Space+드래그 화면 이동.
한글 입력 상태에서도 영문 단축키의 물리적 키 위치를 인식합니다. 텍스트 입력 중에는 단축키가 비활성화됩니다.
직교는 기본적으로 켜져 있으며 선·치수·거리 측정에 적용됩니다.
객체 스냅은 끝점과 선 중간점에 적용됩니다.
자르기와 연장은 선 객체를 대상으로 하며, 경계는 선, 사각형, 원입니다. 자르기는 제거할 구간을 클릭합니다.
간격띄우기는 선을 클릭한 뒤 간격을 입력합니다. 음수를 입력하면 반대 방향입니다.

DXF는 기본 도형 내보내기만 지원하며 치수 텍스트가 포함되지 않습니다. DXF 불러오기, 원 자체 자르기, 다중 선택과 실제 레이어 편집은 지원하지 않습니다. 설계용 실무 배포 전 결과의 검증이 필요합니다.
