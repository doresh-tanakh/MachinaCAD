MachinaCAD 0.1.9 개발 버전
웹: 압축을 풀고 웹 서버에 올려 index.html을 엽니다.
단색 해치: 닫힌 폴리라인 또는 사각형을 선택하고 단색 채우기를 누릅니다. 생성된 해치는 원래 경계와 연결되지 않습니다.
블록: 여러 객체를 선택해 블록 만들기로 묶고 블록 분해로 풀 수 있습니다. 같은 원본 정의를 공유하는 인스턴스 전체를 한 번에 편집하는 기능은 없습니다.
스플라인: 선택 후 제어점을 드래그해 편집합니다. 주기적 스플라인은 제어점 드래그를 지원하지 않습니다.
다중행 문자는 일반 텍스트와 줄바꿈만 지원합니다. 서식과 자동 줄바꿈은 지원하지 않습니다.
DXF: 일부 비균일 축척 블록, 일반 다중행 문자, 폴리라인 경계의 단색 해치를 지원합니다. 외부 참조, 패턴 해치, 완전한 치수와 모든 속성 및 공유 블록 정의 보존은 미지원입니다. 미지원 데이터에 대한 경고를 확인하세요.
유리 스플라인과 고차 스플라인의 SVG/PDF 출력은 근사됩니다. 이전 버전은 새 .mcad 파일을 읽지 못할 수 있습니다.
브라우저 화면 및 설치 후 실행은 검증하지 못했습니다. 중요한 도면은 원본 백업 후 사용하세요.
