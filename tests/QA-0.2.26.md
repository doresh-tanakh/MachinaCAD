# OlplotCAD 0.2.26 검증 결과

2026-11-03 · macOS Apple Silicon

## 구현

- 회로도: 2~256핀 IC, 핀 이름·번호·전기 유형, U 단축키, 다핀 PCB 기본 배치 전달, 구동 충돌·전원/입력 연결 기본 검사.
- PCB: 사각·타원·둥근 사각·연결된 복합 SMT 패드, 형상 기반 선택·충돌/간격 검사 및 출력.
- 구리면: 다각형 경계, 보드 안쪽 클리핑, 다른 네트 간격, 써멀/직접 연결, 우선순위, 미연결 섬 제거, 수정 뒤 재채움 검사. UI 새 경계는 사각형이며 가져온 다각형도 보존.
- KiCad: 단일 시트 다핀 IC와 패드 형상·구리면 입출력. 용지 밖 음수 좌표를 양수 용지 좌표로 변환하고 OlplotCAD 원점을 기록하여 재가져오기 때 복원.
- 제조: 복합 패드·구리면 Gerber 영역과 원형 관통 홀. 내부 구멍이 채워지지 않도록 cut-in 윤곽을 출력.
- Clipper 6.4.2(Boost Software License 1.0)를 고지와 함께 배포. Electron 빌드 lockfile의 잘못된 tmp 버전을 고치고 깨끗한 의존성 설치 확인.

## 남은 범위

전체 KiCad 호환이나 전체 ERC/DRC 완료를 의미하지 않습니다. IC 시뮬레이션 모델, 계층/다중 유닛 회로도, 버스, 검증된 부품 라이브러리, 내부 동박층, 슬롯/NPTH/편심 드릴, 비사각 보드 외곽, 자동 배선은 남아 있습니다. 자동 패드는 일반 DIP형 기본 배치입니다. 곡선 동박은 다각형 근사이며 형상 정밀도와 꼭짓점 수 제한이 있습니다. 전용 문서 버전은 26이며 이전 앱은 새 파일을 열 수 없습니다. 설치 파일은 미서명·미공증 개발용입니다.

제조 파일은 독립 CAM 도구와 제조사 규칙으로 추가 검토해야 합니다. 표본 검사로 모든 설계의 제조 적합성을 보증하지 않습니다.
