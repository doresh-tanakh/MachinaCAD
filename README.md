# OlplotCAD

기계제도, 건축제도, 회로도와 PCB 레이아웃을 각각의 편집창에서 다루는 웹·데스크톱 CAD 프로젝트입니다. 

**현재 버전: 0.2.26 개발판. 전체 CAD 기능이나 완전한 KiCad/DXF 호환이 완료된 제품은 아닙니다.**

## 작업 공간

새 파일에서 **기계제도 / 건축제도 / 회로도 / PCB 레이아웃** 중 하나를 선택합니다. 각 문서는 선택한 분야로 고정됩니다. 분야마다 필요한 도구와 단축키만 표시되며, 다른 분야는 별도 문서 탭으로 엽니다. 탭마다 도형·레이어·실행 취소 기록과 화면 위치를 따로 유지합니다. 저장은 현재 문서에 적용되므로 각 문서를 따로 저장하세요.

상단 리본에는 그리기·수정·주석·분야별 도구를 배치했습니다. 왼쪽 속성 패널과 중앙 도면, 문서 탭, 하단 수치·스냅 상태를 함께 사용할 수 있습니다. 색상은 차콜과 파스텔 그린을 사용합니다.

## 파일

| 용도 | 확장자 | 현재 지원 |
|---|---|---|
| 모든 분야의 기본 저장 | **`.olpcad`** | 도형·레이어·분야·회로/PCB 연결 정보 보관 |
| 이전 전용 파일 | `.mcad` | 읽기 지원. 혼합 도면은 분야별 문서로 분리 |
| 기계·건축 교환 | `.dxf` | ASCII DXF 부분 호환. 전용 벽·회로·PCB 데이터는 도형으로 출력 |
| 회로도 교환 | `.kicad_sch` | 아래에 명시한 단일 시트 R/C/L/V·2~256핀 IC·배선·접지·네트 라벨 부분 호환 |
| PCB 교환 | `.kicad_pcb` | 2층 직선 배선·원/사각/타원/둥근 사각/복합 패드·구리면·관통 비아·사각 외곽 부분 호환 |
| 회로 계산용 | `.cir` | 선형 RLC SPICE 넷리스트 출력. 도면 배치를 포함하지 않음 |
| 제조 데이터 | Gerber `.gbr`, Excellon `.drl` | 제한된 2층 보드의 동박·패드 마스크·사각 외곽·도금 관통 홀 ZIP |
| 문서 출력 | `.svg`, PDF | SVG 출력, 인쇄 대화상자를 통한 PDF 저장 |

기본 **저장**은 분야에 관계없이 `.olpcad`를 만듭니다. KiCad·DXF·SPICE는 **내보내기**에서 선택합니다. 새 전용 문서 버전은 26입니다. 이전 프로그램으로 새 파일을 열 수 없으므로 원본은 별도로 보관하세요.

## 분야별 기능

- **기계제도:** 선·폴리라인·원·호·타원·스플라인, 치수, 자르기·연장·간격띄우기, 해치, 블록 내부 편집, 레이어, 스냅·직교·수치 입력 등 기존 2D 기능.
- **건축제도:** 두께가 있는 직선 벽과 부착 문·창 개구부, 겹침·범위 검사, 닫힌 직선 실 영역의 면적·둘레.
- **회로도:** 두 단자 R/C/L/V, 2~256핀 IC와 핀 이름·종류 편집, 접지와 배선. IC 시뮬레이션 모델은 지원하지 않습니다. 도면 연결에서 넷리스트 생성, DC 동작점과 단일 주파수 선형 AC 크기·위상 계산, 기본 연결 검사.
- **PCB:** 회로도에서 패드·네트를 PCB 편집창으로 전달, 기존 PCB를 열린 회로도에 연결해 네트 갱신, 부품·핀 매핑 검사, 미연결 안내선, 네트·동박층·폭 지정과 연속 직선 배선, 기본 기하 검사.

PCB의 자동 생성 패드는 두 핀 또는 다핀 DIP형 기본 배치이며 검증된 부품 풋프린트 라이브러리가 아닙니다. 실제 부품 치수·핀 배치·제조 규칙을 확인해야 합니다. 안내선은 연결 상태를 보여 주며 배선이나 제조 객체가 아닙니다.

구리면은 사각 보드 안의 다각형 경계를 채우며, 네트 간 간격·써멀 연결·우선순위·고립 섬 제거를 적용합니다. 배치 수정 후에는 다시 채워야 제조 출력할 수 있습니다. 복합 패드는 같은 네트·층의 연결된 SMT 패드를 합쳐 만듭니다. 곡선 동박은 0.0001 mm 목표 오차의 다각형으로 계산되며 꼭짓점 수 제한에 따라 오차가 커질 수 있습니다.

## 단축키

| 분야 | 주요 키 |
|---|---|
| 기계제도 | L 선 · P 연속선 · R 사각형 · C 원 · A 호 · D 치수 · T 자르기 · E 연장 · O 간격띄우기 |
| 건축제도 | W 벽 · B 문 기호 · N 창 기호 · L 선 · D 치수 |
| 회로도 | W 배선 · R 저항 · C 커패시터 · L 인덕터 · S 전압원 · G 접지 · U IC |
| PCB | B 보드 외곽 · W 배선 · P 패드 · Z 구리면 |

공통: V 선택, M 이동, X 문자, Shift 임시 직교, Esc 취소, Ctrl/⌘ N 새 파일, O 열기, S 저장, Z 실행 취소, Shift Z 다시 실행. Ctrl Tab은 열린 문서를 전환합니다. 입력 필드에서는 도구 단축키가 실행되지 않습니다. 실제 입력과 브라우저 예약 키 동작은 실행 환경에 영향을 받습니다.

F1 도움말, F2 기록, F3 자석, F7 격자 표시, F8 직교, F9 격자 스냅, F12 수치 입력을 지원합니다. 3D 기능 키 F4/F6은 미지원입니다.

## 예제

`examples/`의 건축·회로·PCB 파일을 각각 열어 시험할 수 있습니다. 회로도와 PCB를 따로 연 뒤 PCB의 **회로도 연결**에서 회로 문서를 선택하면 기존 배치를 유지하면서 네트를 적용할 수 있습니다. PCB 예제는 미배선 상태라 기하 검사에서 끊긴 네트를 보고하는 것이 정상입니다.

## 실행과 빌드

웹은 파일들을 같은 폴더에 두고 `index.html`을 엽니다. 데스크톱 개발 환경은 다음과 같습니다.

```sh
npm ci
npm start
# macOS에서 해당 아키텍처 빌드
CSC_IDENTITY_AUTO_DISCOVERY=false npm run build:mac:arm64
CSC_IDENTITY_AUTO_DISCOVERY=false npm run build:mac:x64
# Windows x64 설치 파일
npm run build:win
```

현재 설치 파일은 인증서가 없는 미서명 개발용 빌드입니다. Mac 0.2.25 PKG 설치 후 선 그리기·저장·재열기, 0.2.26 설치 후 IC 배치·저장과 PCB 구리면 표시를 확인했습니다. KiCad 10.0.8 실제 PCB 편집기에서 복합 패드·구리면 표본을 열고, 실제 엔진으로 16핀 회로도·PCB SVG 출력을 확인했습니다. 16핀 표본의 회로도 GUI 확인은 파일 선택창 제어 문제로 완료하지 못했습니다. Windows 설치 후 실행과 독립 웹 브라우저 화면은 미검증입니다.

## 검증과 제한

20개 Node 검사 모음에 분야 격리·문서 상태·단축키, 기본 저장과 `.mcad` 호환, KiCad 입출력·핀 좌표·라벨 연결, PCB 안내선, 기존 2D/DXF 검사를 포함합니다. 별도 KiUtils 파서로 KiCad 표본 구조를, Gerbonara로 Gerber/Excellon 표본 좌표·폭·홀·극성을 확인했습니다. 실행 방법은 [tests/README.md](tests/README.md)를 참고하세요. 이 검사는 실제 제품 실행이나 모든 파일의 호환을 보증하지 않습니다.

아직 남은 주요 기능:

- 자동 벽 접합, 곡선벽·다층 건축/BIM, 복잡한 실 경계.
- 과도·비선형·디지털 회로 해석, IC 시뮬레이션 모델과 검증된 심볼/풋프린트 라이브러리, 전체 ERC.
- 내부 동박층, 슬롯·비도금 홀·편심 드릴, 복잡한 외곽, 자동 배선, 전체 DRC.
- KiCad 계층/다중 유닛 회로도·버스·이미지·전체 속성/서식 보존. 지원 범위 밖 객체는 가져올 때 경고하며 전체 파일을 완벽히 왕복 보존하지 않습니다.
- 공유 블록 정의, 혼합 문자 서식, 완전한 치수 스타일과 DXF 속성 보존 등 기존 DXF 제한.

제조 ZIP 출력과 기본 검사 통과는 제조 승인이 아닙니다. 모든 층·홀·원점과 적층/완성 홀 조건을 독립 CAM 도구와 제조사 기준으로 확인하세요.
